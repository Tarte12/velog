# 1. 무선 랜의 구조
## 1.1 무선 랜
- 랜 케이블 없이(무선) 전파를 이용해 컴퓨터를 연결하는 방식
- 유선보다 속도가 불안정하고 전파가 약하면 연결이 잘 안 될 수 있음
- 해킹될 위험이 높아 반드시 암호화나 인증 설정 필요
- 무선 액세스 포인트 + 무선 클라이언트로 구성
- **무선 액세스 포인트(Wireless Access Point; WAP; 무선 공유기; 무선 AP)**
	- 무선 인터넷 사용자가 인터넷 서비스를 이용할 수 있도록 무선 인터넷 접속을 도와주는 중계 장치
    - 무선 공유기에 내장
- **무선 클라이언트(컴퓨터, 스마트폰)**
	- 컴퓨터가 WAP와 통신하려면 무선 랜 칩과 무선 랜 어댑터(USB 메모리 방식 or 컴퓨터 카드 방식) 필요

## 1.2 인프라스트럭처 방식/애드혹 방식
- 통신 방식: 인스트라스트럭처, 애드혹
- **인트라스트럭처**(Infrastructure) 방식
	- WAP을 통해 통신하는 방식
    - 일반적으로 사용하는 방식
- **애드혹(Ad Hoc) 방식**
	- 무선 클라이언트끼리 직접 통신하는 방식
    
## 1.3 무선 랜 규격

- 무선 랜 규격 `IEEE802.11`
	- 미국 기술 표준화 단체인 IEEE(Institute of Electrical and Electronics Engineers)에서 승인한 무선 랜의 표준화 기술
	- 다양한 규격이 존재
	- 무선 공유기가 예를 들어 `IEEE802.11ac`를 지원하더라도 무선 클라이언트가 그 규격을 지원하지 않으면 사용할 수 없음

# 2. SSID의 구조
## 2.1 SSID
- 무선 액세스 포인트와 무선 클라이언트 연결 => 혼선을 피하기 위해 **SSID 사용**
- 무선 클라이언트가 자동으로 무선 액세스 포인트를 찾을 수 있도록 **네트워크 이름/인증/암호화/암호화 키 설정**
- **SSID**(Service Set IDentifier): 액세스 포인트의 고유 이름

### 무선 액세스 포인트와 무선 클라이언트 연결 과정
1. 무선 액세스 포인트가 **비콘**(beacon: 자기를 알리는 신호) 전송
2. 무선 클라이언트가 비콘을 잡은 후, **자신의 SSID와 같은지** 무선 액세스 포인트에 문의
3. 같은 SSID라면 무선 액세스 포인트가 응답
4. **설정된 인증 방식이 올바른지 확인**한 후, 무선 클라이언트가 무선 액세스 포인트에 **연결 요청**
5. 무선 액세스 포인트가 승인

## 2.2 채널
- 채널:
	- 여러 기기를 통시에 연결할 수 있도록 무선 랜이 분할한 주파수 대역
    - 전파가 겹치는 무선 액세스 포인트에 **서로 다른 채널을 설정**
    - **주파수가 달라** 전파가 겹쳐도 **서로 간섭이 발생하지 않아** 통신 속도의 저하 발생 X
    - 무선 액세스 포인트와 무선 클라이언트 거리가 멀수록 통신 속도가 느려짐
    => 이것을 해결하기 위해 무선 액세스 포인트를 여러 대 설치
- 채널의 설정:
	- 무선 액세스 포인트가 기본적으로 알아서 최적의 채널을 찾음
    - 자동 설정이 불안정한 연결이나 통신 속도 저하의 원인이 될 수 있음
    => 수동으로 채널을 변경해서 문제 해결 가능
