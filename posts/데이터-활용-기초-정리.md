rvest :  HTML 웹문서 읽기 및 문자열 추출 패키지
read_html(url, encoding="utf-8)
- read_html : 지정된 URL의 HTML 문서를 읽어오는 함수
html_nodes(html, "table tr td")
- html_nodes : 지정한 HTML 요소를 모두 선택하는 함수
%>% 파이프 연산자 : 앞의 결과를 다음 함수로 전달
html_text() : 선택한 HTML 요소에서 텍스트 추출
gsub() : 문자열 대체 함수

paste() : 여러 개의 문자열과 매개변수를 합쳐 하나의 요청 URL 문자열 만드는 함수
URLencode() : URL에 포함된 특수문자, 공백 등을 URL 규격에 맞게 인코딩
GET() : httr 패키지를 사용하여, HHTP GET 요청을 보냄
status_code() : HTTP 응답 상태 코드 확인
content(response, "text") : API에서 반환된 응답 데이터를 텍스트 형태로 가져옴
xmlParse() : 반환된 텍스트 데이터를 XML 형식으로 파싱

nouns(iconv())
- 텍스트 데이터에서 명사 추출 함수
- RmecabKo 패키지 안에 있음
- 입력으로 들어온 텍스트에서 명사만 추출해 리스트 형태로 반환
- iconv() : 문자 인코딩 문제 해결

unlist()
- 리스트 형태의 데이터를 벡터로 변환
- 데이터가 리스트로 나눠져 있을 때 하나의 긴 벡터로 통합

nouns.all[nchar() >= 2]
- nouns.all 벡터에 있는 단어 중 길이가 2글자 이상인 단어만 선택
- nchar() : 문자열 길이 계산

table()
- 데이터에서 각 요소의 빈도수 계산

[order(-nouns.df$Freq)]
- 데이터 프레임 내 특정 열을 기준으로 내림차순 정렬
- order() : 인자로 주어진 열을 기준으로 인덱스 정렬

wordcloud2()
- 단어의 빈도를 기반으로 워드 클라우드 시각화하는 함수
- 많이 등장한 단어가 더 크게 보임

str() : 데이터 구조 요약 출력 함수
summary() : 데이터의 통계 요약 정보 제공 함수
nzchar() : 각 문자열이 빈 문자열인지 확인
apply() : 행 또는 열을 기준으로 사용자 지정 함수 적용
colSums() : 각 열의 합계 계산
rowSums() : 각 행의 합계 계산
is.na() : 데이터에서 결측값 확인
sum(is.na()) : 데이터에서 결측값 총 계수 계산
colSums(is.na()) : 각 열에서 결측값 개수 계산
rowSums(is.na()) : 각 행에서 결측값 개수 계산
is.infinite() : 데이터에서 무한대(Inf) 값 확인
sum(is.infinite()): 무한대의 개수 계산
na.omit() : 결측값을 포함하는 행 제거
filter() : 조건을 만족하는 행만 필터링
subset() : 조건을 만족하는 행과 선택된 열로 데이터의 하위 집합 생성
is.nan(0 : not a number(nan) 확인
mean() : 벡터 평균 계산
median() : 벡터 중앙값 계산
max() : 벡터 최대값 반환
min() : 벡터 최소값 반환

igraph : 네트워크와 그래프 분석을 위한 패키지
make_star() : 중심 노드와 주변 노드로 이뤄진 별 모양 그래프 생성
set_vertex_attr() : 그래프 노드에 속성 설정
plot() : 그래프를 시각적으로 플로팅
tkplot() : 대화형 그래프 플로팅 도구
make_graph() : 그래프 생성
