7. 객체 지향 분석 방법론

### 3과목 데이터베이스 구축

43. DB 설계 단계
- 개념적 설계 : 개념 스키마 모델링, 트랜잭션 모델링, 독립적 개념 스키마 설계, E-R 다이어그램
- 논리적 설계 : 트랜잭션 인터페이스 설계, 스키마 평가 및 정제, 목표 DBMS에 맞는 논리 스키마 설계, 논리적 구조의 데이터로 모델화
- 물리적 설계 : 저장 구조 및 액세스 경로 설정, 레코드 집중 분석 및 설계, 저장 레코드 양식 설계

44. 카디널리티, 차수
- 카디널리티 : 튜플의 수(행의 수) <- 맨 왼쪽
- 차수 : 속성의 수(열의 수) <- 맨 위쪽

50. 시스템 카탈로그
- 시스템 그 자체에 관련 있는 다양한 객체에 관한 정보를 포함하는 시스템 데이터베이스
- 시스템 카탈로그 내의 각 테이블은 사용자를 포함해 DBMS에서 지원하는 모든 데이터 객체에 대한 정의 or 명세에 관한 정보를 유지, 관리하는 시스템 테이블
- 갱신은 시스템이 자동 갱신

### 5과목 정보시스템 구축 관리

- 대칭 키 암호화 알고리즘 : AES
- 비대칭 키 암호화 알고리즘 : 디피-헬만, RSA

84. 나선형 모형
- 계획 및 정의 -> 위험 분석 -> 공학적 개발 -> 고객 평가

89. 블록체인
1) OTT(오버더탑)
- 개방된 인터넷을 통해 방송 프로그램, 영화 등 미디어 콘텐츠 제공 서비스
2) SDDC(Software Defined Data Cener)
- 소프트웨어 정의 데이터 센서
- 데이터 센터의 모든 자원이 가상화되어 서비스, 소프트웨어 조작만으로 자동 제어
3) Wi-SUN
- 스마트 그리드와 같은 장거리 무선 통신을 필요로 하는 사물 인터넷 서비스를 위한 저전력 장거리 통신 기술
4) BaaS(Blockchain as a Service)
- SNS, 위치 서비스와 같은 백엔드 기능을 클라우드화하는 모바일 앱 개발에 주로 사용하는 클라우드 서비스
