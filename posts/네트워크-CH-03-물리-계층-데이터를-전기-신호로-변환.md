## 1. 물리 계층의 역할과 랜 카드의 구조

### 1.1 전기 신호
- 0과 1로 이뤄진 비트열을 전기 신호로 변환하려면 **물리 계층**의 기술이 필요
- 네트워크를 통해 데이터를 주고받을 땐 0과 1의 비트열을 전기 신호로 변환해야 함
- 전기 신호 종류:
   	
    - **아날로그 신호**: 물결 모양의 연속적인 값을 가지는 전기 신호
    	- 보통 전화 회신, 라디오 방송에서 사용
        - 많은 정보를 포함하지만 취약한 점이 많고 처리가 어려움
    - **디지털 신호**: 막대 모양 비연속적인 값을 가지는 전기 신호
    	- 아날로그 신호보다 안정적이고 처리하기 쉬움
        - 하지만 더 적은 정보를 가짐

![](https://velog.velcdn.com/images/emprimula/post/48909885-c167-456f-896b-55d70ad7c321/image.jpg)
	<BR>
 - 데이터 송신 측에서 0과 1로 이뤄진 데이터를 전기 신호(데이터 신호)로 변환해서 보내면,
 - 수신 측에서 다시 신호를 0과 1로 변환하는 구조
![](https://velog.velcdn.com/images/emprimula/post/dcf6aee5-09b4-4331-b475-7b2b6ebc1f7f/image.png)

### 1.2 랜 카드
> 그렇다면 0과 1의 데이터를 어떻게 전기 신호로 변환하는가?

- 컴퓨터는 네트워크를 통해 데이터를 송수신할 수 있도록 **랜 카드**가 메인 보드에 포함되어 있는 **내장형 랜 카드**나ㅏ 별도의 랜카드를 가짐
- **랜 카드**: 0과 1의 정보가 컴퓨터 내부에 있는 랜 카드로 전송되고, 랜 카드는 0과 1을 전기 신호로 변환
  - 랜 카드 덕분에 네트워크에서 데이터를 주고받을 수 있는 것
<BR>
  
> **물리 계층**이
 > 컴퓨터와 네트워크 장비를 연결하고,
 > 네트워크 장비 간의 전송되는 데이터를 전기 신호로 변환하기 위한 계층

## 2. 케이블의 종류와 구조

### 2.1 트위스트 페어 케이블 
  - 트위스트 페어 케이블 <= 랜 케이블(LAN cable) 안에 들어감
  - ** 전송 매체**: **데이터가 흐르는 물리적인 선로** => **유선/무선**으로 나뉨
  	- 유선: 트위스트 페어 케이블, 광케이블
  	- 무선: 라디오파, 마이크로파, 적외선
  - 트위스트 페어 케이블(twist pair cable): `UTP`, `STP`
  	- UTP 케이블: 구리 선 여덟 개를 두 개씩 꼬아 만든 네 쌍의 전선으로 **실드(shield)로 보호되어 있지 않은 케이블**
  		- Unshielded Twist Pair = 비차폐 연선
  		- 실드: **금속 호일이나 금속의 매듭과 같은 것**
  		- 외부에서 발생하는 노이즈(noise)를 막는 역할
  		- UTP 케이블은 실드로 보호되지 않아 노이즈의 영향을 받기 쉽지만, 저렴하여 일반적으로 많이 사용
  	- STP 케이블: 두 개씩 꼬아 만든 선을 실드로 보호한 케이블
  		- UTP 에 비해 노이즈의 영향을 매우 적게 받지만, 비싸기 때문에 보편적으로 사용 X
  	- 노이즈는 언제 발생하는가? **케이블에 전기 신호가 흐를 때**
  		- 그래서 노이즈의 영향을 적게 받도록 구리 선 두 개를 비틀어 꼬아서 케이블을 만드는 것
  	![](https://velog.velcdn.com/images/emprimula/post/7394c6d9-bee3-4087-b5f2-c0c4bdf857ee/image.png)

### 2.2 랜 케이블: 다이렉트 케이블, 크로스 케이블

- **다이렉트 케이블**: 구리 선 여덟 개를 **같은 순서**로 커넥터에 연결한 케이블
  - **컴퓨터와 승위치를 연결할 때** 사용
  ![](https://velog.velcdn.com/images/emprimula/post/bc5728a0-358e-4622-a515-87417e72c6c8/image.png)

- **크로스 케이블**: 구리 선 여덟 개 중 한쪽 커넥터의 **1번**과 **2번**에 연결되는 구리 선을 다른 쪽 커넥터의 **3번**과 **6번**에 연결한 케이블
  - **컴퓨터 간에 직접 랜 케이블로 연결할 때** 사용
![](https://velog.velcdn.com/images/emprimula/post/5930b90b-83d3-4aff-a0c1-28eb954ae8b3/image.png)

- 두 케이블 모두 나머지 선 4개는 사용하지 않음
- 데이터를 보낼 때 두 케이블 모두 1번과 2번 사용
- 양쪽 컴퓨터에서 1번과 2번으로 데이터를 전송한다면? => 충돌
- 그래서 크로스 케이블은 일부러 중간에 전선을 교차시켜 송신 측과 수신 측이 올바르게 연결되도록 함

## 3. 리피터와 허브의 구조

### 3.1 리피터
  - **리피터(repeater)**: 전기 신호를 정형(일그러진 전기 신호 복원)하고 증폭하는 기능을 가진 네트워크 중계 장비
  - 멀리 있는 상대방과도 ㅅ=통신할 수 있게 파형을 정상으로 만드는 기능 수행
  - 요즘은 다른 네트워크 장비가 리피터 기능을 지원해서 리피터 쓸 필요 X
  ![](https://velog.velcdn.com/images/emprimula/post/791f3701-f2c2-403a-b0c6-5dbf053cf6ed/image.jpg)

### 3.2 허브
  - **허브(hub)**: 리피터와 마찬가지로 **전기 신호를 정형하고 증폭하는 기능**을 하는 물리 계층에서 동작하는 네트워크 장비
  	- 컴퓨터가 보낸 전기 신호가 허브에 도착하는 동안 노이즈의 영향으로 파형이 변경될 때가 있음 => 이럴 때 허브가 파형을 정상으로 되돌리는 기능을 함
  	- **포트**(실제로 통신하는 통로)를 여러 개 가지고 있고 리피터 허브라고 불림
  	- 리피터는 일대일 통신만 가능, 허브는 포트를 여러 개 가지고 있어 => 컴퓨터 여러 대와 통신 가능
  ![](https://velog.velcdn.com/images/emprimula/post/69c2d00d-aa44-426a-8d84-8297dd9ee9e3/image.png)
- 허브는 컴퓨터 여러 대를 서로 연결하는 장치 => 직접 컴퓨터끼리 연결하지 않아도 통신 가능
- 하지만 어떤 특정 포트로부터 데이터를 받을 경우 => 해당 포트를 제외한 **나머지 모든 포트로도 받은 데이터를 전송**하는 특징 존재
- 컴퓨터 1에서 컴퓨터 2로 데이터를 전송한다면, 컴퓨터 2에만 전송되는 게 아니라 컴퓨터 3~5 모두에게 불필요하게 데이터가 전송됨
  - **더미 허브**(dummy hub): 스스로 판단하지 않고 전기 신호를 모든 포트로 보내기 때문에 이렇게 불리기도 함

  > **이 비효율적인 문제의 대책은?** => **스위치(switch)**
