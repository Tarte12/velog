## 1. 데이터 링크 계층의 역할과 이더넷
### 1.1 이더넷
- 랜에서 데이터를 주고받기 위해 **데이터 링크 계층**의 기술이 필요
- **데이터 링크 계층**: **네트워크 장비 간에 신호를 주고받는 규칙**을 정하는 계층
	- 랜에서 데이터를 정상적으로 주고받기 위해 필요한 계층
- **이더넷(Ethernet)**: 주고받는 규칙들 중 일반적으로 가장 많이 사용되는 규칙
	- 랜에서 적용되는 규칙
	- 허브와 같은 장비에 연결된 컴퓨터와 데이터를 주고 받을 때 사용
    - if) 특정 컴퓨터에만 데이터를 보내는데 다른 컴퓨터들이 데이터를 받는다면? (허브)
    - **규칙** 있음: 보내려는 데이터에 **목적지** 정보를 추가해서 보내고, 목적지 이외의 컴퓨터는 데이터를 받더라도 무시하게 됨
- 충돌(collision): 허브는 들어온 데이터를 그대로 모든 포트에 보내기만 하는데 => 컴퓨터 여러 대가 동시에 데이터를 보내면 이 구조 때문에 데이터들이 서로 부딪힐 수 있음
- 그래서 이더넷은 **여러 컴퓨터가 동시에 데이터를 전송해도 충돌이 일어나지 않는 구조**로 되어 있음
	- 데이터가 동시에 케이블을 지나가면 충돌 => 데이터 보내는 시점을 늦춘다
    - **CSMA/CD**: 이더넷에서 시점을 늦추는 방법
    	- Carrier Sense Multiple Access with Collision Detection(반송파 감지 다중 접속 및 충돌 탐지)
        - **CS**: "데이터를 보내려고 하는 컴퓨터가 케이블에 신호가 흐르고 있는지 아닌지 확인한다"
        - **MA**: "케이블에 데이터가 흐르고 있지 않다면 데이터를 보내도 좋다"
        - **CD**: "충돌이 발생하고 있는지를 확인한다"
        - 위의 규칙으로 데이터를 주고받으면 충돌 X
        - but 효율이 좋지 않기 때문에 **스위치**를 사용해서 충돌을 해결

## 2. MAC 주소의 구조
### 2.1 MAC 주소
- 랜 카드는 비트열(0과 1)을 전기 신호로 변환
- **MAC 주소**: 랜 카드에 적혀진  **전 세계에서 유일한 번호**로 할당된 **물리 주소**
	- Media Access Control Address
    - 제조할 때 새겨지기 때문에 물리 주소라고도 함
    - 중복되지 않도록 규칙이 명확하게 정해져 있음
    - 48 비트 숫자로 구성
    - 앞 24비트: 랜 카드를 만든 제조사 번호
    - 뒤 24비트: 제조사가 랜 카드에 붙인 일련번호
    
 - OSI 모델, TCP/IP 모델에서 각 계층에서 **헤더**를 붙였었음
 - OSI 모델(데이터 링크 계층), TCP/IP 모델(네트워크 계층)에서 => **이더넷 헤더, 트레일러**를 붙임
 
 - **이더넷 헤더**: 14바이트 구성 = [목적지 MAC 주소(6바이트) + 출발지 MAC 주소(6바이트) + 유형(2바이트)] 
 	- **이더넷 유형(Ethenet type)**: 이더넷으로 전송되는 상위 계층 프로토콜의 종류
    	- 유형 번호: **프로토콜 종류를 식별하는 번호**
    	- 0800: IPv4
        - 0806: ARP
        - 8035: RARP
        - 814C: SNMP over Ethenet
        - 86DD: IPv6
 - **트레일러(FCS)**: 데이터 전송 도중에 오류가 발생하는지 확인하는 용도
 	- Frame Check Sequence
 - **프레임**: 이더넷 헤더와 트레일러가 추가된 데이터
 	- 데이터를 통해 프레임이 전송
 
 **네트워크에서 이더넷 헤더를 이용한 통신**
 ![](https://velog.velcdn.com/images/emprimula/post/501a551b-750a-475c-858f-f6ee45311b70/image.png)

1. 컴퓨터 1이 컴퓨터 3으로 데이터 전송
	- 컴퓨터 1은 이 과정에서 이더넷 헤더에 3의 MAC 주소(목적지)와 자신의 MAC 주소(출발지) 정보를 넣음
2. 캡슐화
	- 컴퓨터 1에서 캡슐화
    - 데이터 링크 계층에서** [데이터+이더넷 헤더+트레일러] = 프레임** 만들기
    - 물리 계층에서 이 프레임 비트열을  **전기 신호**로 변환하여 네트워크 통해 전송
3. 역캡슐화
	- 1포트로 수신, 2~5포트로 전송
    - 컴퓨터 2, 4, 5에 도착한 **데이터 파기**
    - 컴퓨터 3은 데이터를 수신
    - 컴퓨터 3에서 물리 계층에서 전기 신호로 전송된 데이터를 비트열로 변환
    - 데이터 링크 계층에서 이더넷 헤더와 트레일러 분리
4. IF) 여러 컴퓨터에서 동시에 데이터 전송 => CSMA/CD 방식 사용으로 충돌 방지    

## 3. 스위치의 구조
### 3.1 MAC 주소 테이블
- **스위치**(switch): 랜을 구성할 때 사용하는 단말기 간 스위칭 기능이 있는 통신망 중계 장치
	- 컴퓨터에서 다른 단말기로 패킷(데이터 단위)을 보낼 수 있는 기능이 있음
    - **데이터 링크 계층**에서 동작
    - **레이어 2 스위치** 또는 **스위칭 허브**라고도 불림
    - 장비 외형은 허브와 비슷함
- **MAC 주소 테이블(MAC address table)**: 스위치의 **포트 번호**와 해당 포트에 연결되어 있는 컴퓨터의 **MAC 주소**가 등록되는 데이터베이스
	- 스위치 내부에 존재
    - 스위치의 전원만 켠 상태: MAC 주소 테이블에 등록된 것 없음
    - **프레임**이라는 데이터의 전송: MAC 주소 테이블을 확인하고 출발지 MAC 주소가 등록되어 있지 않을 경우, MAC 주소를 포트와 함께 등록 
    => **MAC 주소 학습 기능**이라고 함
    - 허브(더미 허브)에는 없는 기능
    - **플러딩**(flooding): 스위치가 수신 포트 이외의 모든 포트에서 데이터(프레임)를 송신하는 것
 - **MAC 주소 필터링**: MAC 주소를 기준으로 목적지를 선택하는 것
 	- 이것으로 불필요한 데이터를 네트워크에 전송되지 않게 함

## 4. 데이터가 케이블에서 충돌하지 않는 구조
### 4.1 전이중 통신과 반이중 통신
![](https://velog.velcdn.com/images/emprimula/post/cf7fa94f-2f4b-4520-ad77-63113bf0eb42/image.jpg)

- **전이중 통신 방식**: 데이터의 송수신을 **동시에** 통신하는 방식
	- 데이터를 동시에 전송해도 충돌 발생 X
    - 컴퓨터 간 직접 랜 케이블에 연결하는 방식은 전이중 통식 방식
    - **스위치**는 충돌이 일어나지 않는 구조이기 때문에 **전이중 통신 방식**으로 데이터를 주고 받을 수 있음
    => 따라서 스위치를 사용하는 것이 효율적이다
- **반이중 통신 방식**: 회선 하나로 송신과 수신을 **번갈아가며** 통신하는 방식
	- 데이터를 동시에 전송하면 **충돌** 발생
    - 허브를 사용하면 회선 반이중 통신 방식을 사용하게 됨
### 4.2 충돌 도메인
- **충돌 도메인**(collision domain): 충돌이 발생할 때 그 영향이 미치는 범위
- 허브 같은 경우 **허브에 연결된 모든 컴퓨터 전체**가 해당 => 완전 끔찍...
- 스위치의 경우 각 연결된 컴퓨터에 한정한 충돌 도메인을 가짐(애초에 충돌도 안 일어남)
- 충돌 도메인의 범위가 넓을수록 네트워크가 지연됨

> **ARP(Address Resolution Protocol)**
> 목적지 컴퓨터 IP 주소를 이용해 MAC 주소를 찾기 위한 프로토콜
> **ARP 요청(request)**: 목적지 컴퓨터의 MAC 주소를 알아내기 위해 네트워크 위에서 브로드캐스트를 하는 것
> **ARP 응답(reply)**: 이 요청을 하면 지정된 IP 주소를 갖고 있는 컴퓨터만 MAC 주소를 response함
> **ARP 테이블(table)**: 출발지 컴퓨터에서는 MAC 주소를 얻은 후에 MAC 주소와 IP 주소의 매핑 정보를 메모리에 보관
> IP 주소가 변경되면 => 해당 MAC 주소도 함께 변경되므로 보존 기간을 ARP캐시로 지정하고 일정 시간이 지나면 삭제됨

## 5. 이더넷 종류와 특징
### 5.1 이더넷 규격
- 이더넷은 케이블 종류나 통신 속도에 따라 다양한 규격으로 분류
- 주요 이더넷 규격
	- 10BASE5
    - 10BASE2
    - 10BASE-T
    - 100BASE-TX
    - 1000BASE-T
    - 10GBASE-T
- **BASE** -> 10BASE-T 라면
	- **통신 속도**: 10Mbps
    - **전송 방식**: BASE => **BASEBAND**
    - **케이블 종류**: T
