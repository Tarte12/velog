# Local VS S3 FileUploader 성능 비교 및 분석
**테스트 목적:** 파일 업로드 시 `Local`과 `S3` 방식의 성능을 객관적으로 비교하여 최종 선택에 기술적 정당성을 부여하기 위함

## 테스트 환경
| 항목           | 값              |
| ------------ | -------------- |
| 동시 사용자 (VUs) | 30명             |
| 테스트 시간       | 5분            |
| 파일 크기        | 3MB PNG        |
| 이미지 처리       | 리사이징 + WebP 변환 |

## 성능 비교 결과
| 성능 지표     | Local FileUploader | S3 FileUploader | 차이     | 승자       |
| --------- | ------------------ | --------------- | ------ | -------- |
| 평균 응답시간   | 626ms              | **619.84ms**    | -6ms   | 🏆 S3    |
| 처리량 (TPS) | 7.29 req/s         | **7.5 req/s**   | +0.21  | 🏆 S3    |
| 완료된 요청 수  | 80개                | **85개**         | +5개    | 🏆 S3    |
| 최소 응답시간   | **383ms**          | 411ms           | +28ms  | 🏆 Local |
| 최대 응답시간   | **1.18s**          | 1.51s           | +0.33s | 🏆 Local |
| 95% 백분위수  | **1.13s**          | 1.37s           | +0.24s | 🏆 Local |
| 성공률       | 100%               | 100%            | 동일     | 🤝 동일    |
| 데이터 전송량   | 241MB              | **256MB**       | +15MB  | 🏆 S3    |

## 분석 결과 요약
- **예상과 다른 결과:**
 Local이 더 빠를 것이라는 예상을 깨고, S3가 평균 성능에서 약간 우위.
- **예상:** Local > S3 (디스크가 네트워크보다 빠를 것)
- **실제**: S3 ≥ Local (거의 동등하거나 S3가 약간 더 우수)


## 성능 특성 비교 요약
| 특성    | Local     | S3        | 분석               |
| ----- | --------- | --------- | ---------------- |
| 평균 성능 | 626ms     | **620ms** | S3가 1% 더 빠름      |
| 안정성   | 높음        | 높음        | 둘 다 100% 성공률     |
| 최고 성능 | **383ms** | 411ms     | Local이 7% 더 빠름   |
| 최악 성능 | **1.18s** | 1.51s     | Local이 22% 더 안정적 |
| 처리량   | 7.29      | **7.5**   | S3가 3% 더 높음      |

## 왜 S3가 예상보다 좋았을까?
**가능한 원인 분석:**

1. **AWS SDK 최적화**
- 멀티파트 업로드, 재시도 로직 내장
2. **네트워크 vs 디스크**
- 로컬 디스크 I/O 병목 vs 네트워크 병렬 처리
3. **AWS 인프라 성능**
- 고성능 네트워크 & 스토리지 인프라
4. **JVM 메모리 오버헤드**
- 로컬 파일 쓰기의 버퍼링 비용 존재

## 결론: 기술적 선택의 정당화
- 5 VUs 기준, 성능 차이는 의미 없는 수준 (1% 내외)
- S3 장점: 처리량 우위, 인프라 확장성
- Local 장점: 최악의 응답시간이 낮아 일관성 있음

> - **성능만으로는 우열을 가리기 어려움**
- **운영 효율성과 확장성 측면에서의 아키텍처적 장점이 S3 선택**

### 무엇을 더 생각해 볼 수 있을까?
- 고부하 테스트 (50-100 VUs): 확장성 비교
- 대용량 파일 (10MB+): 네트워크 vs 디스크 특성
- 비용 분석: 운영비용 vs 인프라 투자

### STAR: Local vs S3 FileUploader 성능 비교
**S(Situation):**
- Local과 S3 업로드 방식을 모두 구현한 상황에서, 성능 데이터를 기반으로 기술적 선택의 정당성을 확보하고자 함

**T(Task):**
- 동일 조건에서 Local과 S3의 평균 응답시간, TPS, 안정성 등을 비교하여 실제 운영 환경에서 사용할 저장 방식을 결정

**A(Action):**
- k6로 5 VUs, 3MB 파일 기준 10초간 부하 테스트
- 리사이징 + WebP 처리 포함. 평균 응답시간, TPS, 최대/최소 응답시간, 성공률 등 정량 지표 수집 및 비교

**R(Result):**
- S3가 평균 응답속도 및 TPS에서 약간 우위
- Local은 최소/최대 응답시간에서 더 안정적
- 성능 차이는 1% 내외로 미미했으나, S3의 확장성과 운영 효율성 측면에서 최종 선택
