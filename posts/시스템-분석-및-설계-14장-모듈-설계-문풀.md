14.1 나사-슈나이더만(NS) 도표에서 표현할 수 있는 3가지 제어 구조로써 거리가 먼 것은?
1) 선택 
2) 반복
3) 분기
4) 순차

(3) 분기
- NS 도표는 구조적 프로그래밍에서 사용하는 3가지 기본 제어 구조를 표현
- 순차, 선택, 반복
- 분기는 특정 제어 구조 X, 프로그램 흐름의 일반적인 변화를 의미

14.2 다음은 모듈 설계 도구에 대하여 올바르게 설명하는 것을 2개 선택하라
1) 분석 모델링 도구들은 보조 도구로 이용될 수 있다
2) 흐름도는 텍스트 기반의 명세 도구이다
3) PDL은 박스도라고도 한다
4) 의사코드는 그래픽 기반의 명세 도구이다
5) 활동 다이어그램은 흐름도와 유사한 표기법을 제공한다

(1), (5)

14.3. 다음 중 모듈 설계를 위해 프로그래밍 코드와 유사한 주요 키워드를 이용하여 서술적으로 명세하는 도구로써 가장 거리가 먼 것은?
1) PDL
2) Desicision Tree
3) Pseudo code
4) Structured English

(2)
- PDL, Pseudo Code, Structered English : 서술적이고 코드 유사한 형식으로 명세를 작성하는 도구
- Desision Tree : 의사결정 과정을 트리 구조로 표현하는 그래픽 기반 도구 -> 명세 도구 X

14.6 다음 괄호에 적절한 용어를 적어라
- 슈도코드 혹은 (1)라고 부르는 PDL은 모듈 설게를 위한 대표적인 텍스트 기반 표기법
- 반면에 NS 도표와 (2)는 모듈 설계를 위한 대표적인 그래픽 기반의 표기법
- PDL은 구조적 프로그래밍 방법의 3가지 제어 구조인 (3), (4), (5)에 대한 표기를 지원

Pseudo Code / 박스도 / 순차 / 선택 / 반복

14.7 다음 모듈 설계에 대해 적절하게 설명한 4가지를 선택하라
1) 아키텍처 설계와 비교하여 하위 수준의 설계 의미
2) 소프트웨어 구조 설계와 시스템 구조 설계로 분류 가능
3) 모듈에 대한 알고리즘을 정의
4) 시스템이나 소프트웨어의 구성 요소들 사이의 관계를 정의
5) 컴포넌트 설계라고 부름
6) 모듈을 분해하고 모듈 사이의 인터페이스를 결정

(1), (3), (5), (6)
