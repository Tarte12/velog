### 프로그래밍(코딩) : 컴퓨터에게 시키고 싶은 일들을 동작하게 하는 프로그램을 만드는 것
#### -> 그렇다면 일을 더 효율적으로 처리할 수 있는 방법이 없을까?
#### 자료구조 : 데이터를 어떻게 구성하는가? <구조화된 데이터>
#### 알고리즘 : 데이터를 어떻게 처리하는가? <논리적 절차>
#### 자료구조 + 알고리즘 = 프로그램

### Overview

#### <선형 자료구조>
- 변수
- 배열
- 리스트

#### <비선형 자료구조>
- 맵
- 그래프
- 트리

### Java는 데이터를 어떻게 표현하는가?
자바에서는 Primitive 타입과 Reference 타입 두 개로 데이터가 존재

### 시간복잡도
- 입력되는 데이터 증가에 따른 성능의 변화를 예측!
- 빅오표기법 : O(n)
- 데이터 n개 들어갔을 때 변화 추이를 보겠다는 것
