9.1 객체 모델링을 위한 구문 분석 방법
- 구문 분석 방법은 도메인에 대한 문서 정보로부터 객체 모델 생성을 돕는 효과적인 방법
- 자연어로 작성된 사용사례 시나리오의 문장을 분석하여 문장에 포함된 동사는 (1)에 해당될 수 있으며, 명사는 (2) 혹은 (3)의 후보가 될 수 있음
(1) 연산(메서드)
(2) 클래스(객체)
(3) 속성(특성)

9.2 객체지향 개발 과정에서 요구 추출과 요구 분석 활동에서 생성되는 모델들과 다이어그램에 대한 문제
- 요구 추출 활동에서 수행하는 주요 작업은 비즈니스 모델과 (1) 모델을 생성하는 것
- 이러한 모델들을 생성하기 위해 각각 활동 다이어그램과 (2) 다이어그램을 이용
- 요구 분석 활동에서는 시스템을 기능, 구조, 행위 관점에서 분석
- 기능 관점에서 분석할 때 주요 작업은 사용사례 모델 생성하는 것
- 사용 사례 모델은 다른 말로 (3) 모델이라 하며, 해당 모델을 생성하기 위해 (4) 다이어그램 이용
- 구조 관점에서 분석할 떄 주요 작업은 정적 구조 모델 생성
- 정적 구조 모델은 다른 말로 (5) 모델이라 하며, 해당 모델을 생성하기 위해 이용되는 주요 다이어그램은 (6) 다이어그램
- 행위 관점에서 분석할 때 주요 작업은 동적 행위 모델을 생성하는 것이며, 해당 모델을 생성하기 위해 이용되는 주요 다이어그램은 (7) 다이어그램
(1) 도메인 객체 모델
(2) 클래스 
(3) 기능
(4) 사용사례
(5) 객체
(6) 클래스
(7) 순차

9.3 객체지향 분석 활동은 기능, 정적구조, 동적행위 모델을 생성한다. 각 모델을 생성하기 위한 여러 세부 작업 중 하나를 구체적으로 기술하고, 해당 작업을 수행하기 위해 이용하는 다이어그램을 하나만 적어라.
- 기능 모델 생성 작업 : 사용사례 식별 및 명세 작성
- 사용사례 다이어그램 : 사용자가 시스템을 어떻게 사용하는지, 주요 기능은 무엇인지 시각적으로 표현

9.5 객체지향 시스템 개발 시 수행되는 수많은 작업들 중에 요구추출 활동에서 수행되는 5개의 작업을 적어라.
- 비즈니스 모델 생성 : 고객 및 이해관계자로부터 시스템의 목적과 기대치 파악
- 도메인 정보 소스 파악 : 시스템이 작동할 도메인(업무 영역)을 이해하고, 관련 정보와 개념 정리
- 문제(시스템) 정의서 작성
- 상위수준 사용사례 작성
- 도메인 객체 모델 생성
