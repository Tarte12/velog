2.5 LAN : LAN을 구성하는 기술

2.5.1 LAN
LAN : 회사나 가정에서 PC나 서버를 네트워크에 연결하여 상호 소통이 가능하도록 하는 방식
유선 LAN : 네트워크 케이블을 유선으로 연결한 네트워크
무선 LAN : 네트워크 케이블을 무선으로 연결한 네트워크
사내 LAN : 회사 내에 설치한 네트워크 -> 회사에 따라 인터넷에 연결된 경우 or 그렇지 않은 경우도 있는데, 인터넷에 연결되지 않은 폐쇄된 네트워크 범위가 인트라넷

2.5.2 LAN을 구성하는 기술
- 라우터 : 네트워크의 출입구가 되는 부분에 설치되는 기기 -> 일방향적으로 들어온 데이터의 목적지를 확인하고, 목적지에 가까운 다른 쪽 네트워크에 데이터를 전송
- 허브 : 네트워크의 배선을 분할하는 기기 -> 같은 네트워크의 다른 단말기에 데이터를 전송
- FW : 방화벽, 드나드는 데이터를 확인하고 통신 여부를 조정하는 장치 -> 보안을 강화하는 데에 사용, FW는 역할의 이름이므로 실제 조정하는 기기는 라우터나 서버, 전용 기기 등 다양함
- DMZ : 접속되어 있는 단말기에 자동으로 IP 주소 분배
- 서브넷 : 한 네트워크를 작게 분할한 네트워크

2.6 IP 주소와 DNS :네트워크의 장소를 특정하는 방법
- IP 주소 = 네트워크 주소 
-> but IP 주소는 숫자의 나열이라 알아보기 어렵기 때문에 DNS라는 방식으로 사람이 알기 쉬운 문자열로 바꾸어 주는 것

2.6.1 IP 주소란?
IP 주소 
- 인터넷상에서 서버, 네트워크, PC 등 호스트를 구별하는 주소나 이름표와 같은 것
- 웬 사이트를 볼 때나 데이터를 송수신할 때 사용
- IP 주소는 네트워크에 접속되어 있는 한 호스트(PC나 스마트폰) 1대에 최소 1개 필요
- 단, 특정 호스트와 IP 주소는 고정이라고 할 수 없음
- AWS는 Elastic IP라는 IP  주소가 있어서 변동이 많은 클라우드 서버라도 고정 IP 주소에 접속할 수 있도록 되어 있음

2.6.2 사설 IP 주소와 공인 IP 주소
공인 IP 주소
- 인터넷에서 사용되는 것
- 관리되고 있어서 전 세계에서 어떤 것도 중복되는 일이 없음 -> 따라서 어떤 호스트인지 확인 가능
사설 IP 주소
- 사내 LAN이나 가정 LAN에서 사용되는 IP 주소
- 인터넷에 공인 IP 주소가 필요한 것은 맞으나, 공인 IP 주소의 수는 한정되어 있어 모든 PC에 할당할 수 없음
-> 큰 단위에만 공인 IP를 할당하고, 이 안에 있는 PC는 가정이나 회사 내에서 통신하는 IP를 할당 받음 => 이게 사설 IP 주소
2.6.3 DNS와 도메인
- 서버와 같은 단말기(호스트)는 IP 주소로 식별됨
- DNS : URL에 포함된 이름에 해당하는 서버의 IP 주소를 알려주는 방식
- URL 접속한다고 생각하지만 실제는 DNS가 백그라운드에서 도메인명에 해당하는 IP 주소를 확인하고 그 IP 주소를 가진 서버에 접속함
- 이로 인해 열람자는 UQL만으로 해당 서버에 접속할 수 있게 되는 것
- AWS도 DNS 서비스를 제공하고 있으며 Route 53가 해당됨

2.7 웹의 구조 : 웹 사이트와 관련된 기술
2.7.1 HTML과 웹 브라우저의 구조
- 웬 사이트의 콘텐츠는 HTML이라는 형식으로 기술되어 있음
- HTML 형식은 태그의 구조를 나타내는 문서
- HTML에 기술되어 있는 것은 문자와 구조
- 이미지는 별도의 파일로 저장, HTML에는 이미지를 저장한 장소만 적힘
- 이렇게 각각 파일로 저장하는 문서와 이미지를 웹 브라우저에서 조합하여 한 페이지로 표시함
2.7.2 웹 서버의 구조
웹 서버 
- HTML이나 이미지 파일을 저장함
- 웹 서버용 콘텐츠는 HTML 파일이나 이미지 파일 외에 동영상 파일, PHP이나 Perl로 작성된 프로그램 파일 등으로 구성되어 있다
