# 1장 아마존 웹 서비스 기초 지식
## 1.1 아마존 웹 서비스란 : 아마존이 제공하는 클라우드 서비스

> AWS : 클라우드 컴퓨팅 서비스 중 하나
클라우드 컴퓨팅 서비스 : 서버 및 네트워크 등을 인터넷으로 빌려주는 서비스
 AWS의 다양한 서비스를 조합해 모든 애플리케이션과 인프라 구축 가능

### 특징

1. 시스템 운영에 필요한 서비스 일체 사용 가능 

 -> 여러 사업자에게 각각 빌려야 했던 인프라를 일괄로 빌릴 수 있음
 -> 운영 체제, 웹 서버, DB 서버 등에 필요한 SW까지 통으로 사용할 수 있음
 
2. 서비스 조합이 쉬움

3. 종량제이므로 사용할 만큼만 빌릴 수 있음 

4. 비전문가도 사용 가능

5. 한국어와 한국 원화 결제 가능

6. 보안 기준

7. 글로벌 확장이 쉬움

## 1.2 AWS의 서비스 : 165개 이상의 서비스 제공

1. 165개 이상의 서비스 제공
-> IT 전반과 관련된 인프라 대부분 제공

2. 목적에 따라 다양한 서비스 제공

3. AWS에서 제공하는 서비스
- EC2 : 컴퓨팅 용량 제공 -> 서버, OS, SW 등을 세트로 사용 가능
- S3 : 오브젝트 스토리지 서비스 -> 웹 서버 및 파일 서버용 파일 보관 스토리지로 사용 가능
- VPN : AWS 계정 전용 가상 네트워크
- RDS : 관계형 데이터베이스 6종류 클라우드 이용 가능 서비스
- Route 53 : DNS 서버 -> 웹 서버에 필수인 DNS 기능 제공
- Elastic IP 주소 : 서버에 필수인 정적 공인 IP 주소 제공
- Amazon Managed Blockchain : 블록체인 네트워크를 생성, 관리하는 도구
- Amazon SageMaker : 머신 러닝 모델 구축, 트레이닝, 배포 -> 주피터 노트북 제공
- AWS Cloud 9 : 웹 브라우저로 조작이 가능한 통합 개발 도구
- Amazon GameLift : 게임 호스팅 서비스 -> 멀티 플레이어 대전 등 실시간 데이터 통신을 짧은 대기 시간으로 제공
