> 모두의 네트워크 책 기반으로 정리

## 1. 네트워크의 구조

### 1.1 (컴퓨터) 네트워크: 
- 컴퓨터 사이의 네트워크를 연결한 것
- 두 대 이상의 컴퓨터가 연결되었을 때부터 컴퓨터 네트워크라 할 수 있음
- 컴퓨터 사이에 필요한 데이터(정보)를 주고 받을 수 있음
- 컴퓨터 간의 데이터(파일) 전송, 웹 사이트 열람, 메일 송/수신 같은 일 가능

### 1.2 패킷
> 네트워크 or 인터넷에서 데이터를 주고받기 위해서 **규칙** 필요
=> 이 규칙에 **패킷(packet)** 사용

**패킷**: 컴퓨터 간에 데이터를 주고받을 때 **네트워크를 통해 전송되는 데이터의 작은 조각**
- 큰 데이터가 있더라도 작게 나눠서 보내는 게 규칙
	- 데이터는 택배처럼 작게 포장해서 보냄
    - **패킷 = 택배**
    - **why?** 큰 데이터를 그대로 보내면 그 데이터가 네트워크의 **대역폭**을 너무 많이 차지(점유)해서 패킷의 흐름을 막을 위험이 있음
    - 대역폭(bandwidth): 일반적으로는 네트워크에서 이용가능한 최대 전송 속도로, **정보를 전송할 수 있는 시간당 전송량**을 의미
    
- 작게 조각을 냈기 때문에 목적지에서는 **원래 데이터로 되돌리는 작업** 필요
	 ex)
    - 목적지에 보낸 패킷이 순서대로 도착하지 않을 수 있음
    - 패킷이 전송될 때 네트워크가 지연되어 늦게 도착 or 패킷 누락 가능
    - 목적지에 도착한 패킷은 순서 없이 제각각 도착

 - 그래서 송신 측에서 수신 측으로 패킷을 보낼 때 **각 패킷에 순서대로 번호를 붙여서** 보냄
 - 이 번호에 맞춰 정렬하면 다시 원래 위치로 돌아갈 수 있음
 
## 2. 정보의 양을 나타내는 단위

### 2.1 비트와 바이트

- 디지털 데이터(digital data): 모든 컴퓨터는 숫자 0과 1만 다루는데, 그 0과 1의 집합을 의미
- **비트(bit)**: 0과 1의 정보를 나타내는 최소 단위
- **바이트(byte)**: 
	- 0 또는 1인 숫자 8개의 집합
	- 8비트 = 1바이트
- 컴퓨터는 기본적으로 바이트 단위로 데이터를 읽고 쓰는 작업을 함 => 따라서 디지털 데이터를 만들 때는 8비트를 1바이트로 다루는 것이 좋음
- **문자 코드(character code)**: 숫자와 문자의 대응표
- **ASCII 코드**: 알파벳, 기호, 숫자 등을 다룰 수 있는 **기본적인 문자 코드**
	- A = 65
- 네트워크에 데이터를 전송하는 경우 => 비트 정보를 전기 신화로 변환
=> 실제로는 네트워크에 **전기 신호**가 전송됨

## 3. 랜과 왠

### 3.1 랜과 왠의 차이
> 네트워크는 접속할 수 있는 범위에 따라 크게 두 가지 종류로 나눌 수 있음

- **LAN(랜)**: 건물 안이나 특정 지역을 범위로 하는 네트워크
	- Local Area Network(근거리 통신망) 
	- 가정 or 빌딩 안에 있는 사무실처럼 지리적으로 제한된 곳에서 컴퓨터와 프린터를 연결할 수 있는 네트워크
    - 좁은 범위를 랜 케이블로 연결
    - 연결하는 거리가 짧기 때문에 신호가 약해지거나 오류가 발생할 확률도 낮음
    - 상대적으로 빠름
 - **WAN(왠)**: 지리적으로 넓은 범위에 구축된 네트워크
 	- Wide Area Network(광역 통신망)
    - **인터넷 서비스 제공자(ISP)**가 제공하는 서비스를 사용하여 구축된 네트워크를 의미
    	- ISP: Internet Service Provider 
        	- 인터넷 상용 서비스 사업을 하고 있는 KT, U+, SK 브로드밴드 같은 사업자 의미
    - 랜과 랜을 연결하는 것으로 생각해도 괜찮음
    	- 연결을 인터넷 서비스 제공자의 서비스가 함
    - 멀리 떨어져 있는 랜과 연결되어 있어 신호가 약해지거나 오류가 발생할 확률이 높음
    - 상대적으로 느림
 
## 4. 랜 구성

### 4.1 가정에서의 네트워크 구성
![](https://velog.velcdn.com/images/emprimula/post/90ad5e2c-73b5-4c65-8918-6aa9d49c4758/image.png)
- **랜**: 집에서 구성하는 네트워크
- **인터넷 서비스 제공자**
- **인터넷 회선**: 광랜을 사용하는 사람이 많음
	- 인터넷을 개통할 때 보통 인터넷 서비스 제공자와 인터넷 회선 두 가지를 결정함
- **인터넷 공유기**: 인터넷 서비스 제공자와 네트워크를  연결하기 위해 필요한 장비
	- broadband router(브로드밴드 라우터)
    - 가정이나 소규모 기업에서 인터넷에 접속할 때 쓰임
    - 가정용으로 만든 라우터라고 생각하면 됨
    - 최근에는 라우터 기능뿐만 아니라 허브, 스위칭 허브, 방화벽 같은 기능도 제공
    > 라우터, 허브, 스위칭 허브가 뭔데?
    > 인터넷 공유기 역할 => CH 05 라우터의 구조에서 설명
    
 - 인터넷 공유기를 중심으로 내부 인터넷망(사설망)을 구성하고 다양한 기기를 연결할 수 있음
 - 연결 방식:
	
    - **유선**: 랜 케이블 필요 (유선 랜)
    - **무선**: 랜 케이블 X (무선 랜)
	
### 4.2 소규모 회사에서 하는 네트워크 구성
![](https://velog.velcdn.com/images/emprimula/post/f5d6ca25-7d6a-4e88-b7e5-794dbc3d04ae/image.png)
- 소호 기업(SOHO)
	- Small Office/Home Office
    - 소규모 회사 의미
- 가정이랑 가장 크게 다른 점은 **DMZ**라는 네트워크 영역의 존재
- **DMZ**: **외부에 공개하기 위한 네트워크**	
   - Demilitarized Zone
   - 인터넷 공유기(라우터)를 통해 외부에 노출된 컴퓨터(네트워크)
   - 외부에 어떤 것을 공개하는가? **서버**
   	- 보통 웹 서버, 메일 서버, DNS 서버를 공개
    - **웹 서버**: 웹 사이트를 불특정 다수의 외부 사용자에게 공개
    - **메일 서버**: 외부 사용자와 메일을 주고받기 위해 공개
    - **DNS 서버**: 외부에서 도메인 이름을 사용하여 회사의 서버에 접속하기 위해 공개
 - 직원의 수가 많을수록 스위치 같은 장비가 늘고 랜 케이블의 배선이 늘어날 것
 > 스위치? CH 14 데이터 링크 계층에서 소개
 
 - 회사에서는 서버 운영을 위해 서버를 사내에 설치하거나 **데이터 센터**에 두거나 **클라우드(cloud)**에 둘 수 있음
     - 데이터 센터: 대량의 데이터를 보관하기 위해 데이터 센터 서버나 네트워크 기기를 설치한 전용 시설
     - 클라우드: 인터넷을 통해 소프트웨어나 하드웨어 등의 컴퓨팅 서비스를 제공하는 것으로, 인터넷에 접속하기만 하면 언제 어디서든 이용 가능
    - 온프레미스(on-premise): 사내 or 데이터 센터에 서버를 두고 운영하는 것 
 - 각 서버나 컴퓨터는 스위치나 무선 랜 기능을 사용해 사내 랜에 접속
