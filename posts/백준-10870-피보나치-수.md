문제 : 피보나치 수열
설계 : 피보나치 수열을 재귀함수 형식으로 함수를 만들어서 호출하면 되지 않을까?
문제점 : 런타임 에러 
- pypy3으로 바꾸기 : 실패
- 코드 추가 : 실패 
import sys
input = lambda: sys.stdin.readline().rstrip()
- n의 범위 설정 : 성공
=> n의 범위를 설정하지 않아, n이 엄청 숫자가 커지면 연산 과정이 길어져서 런타임 에러가 발생하는 듯하여, 문제 조건인 20 이하의 자연수인 n 조건을 추가하였음
```
import sys
input = lambda: sys.stdin.readline().rstrip()

def func(n) :
	if n == 0 :
		return 0
	if n == 1 or n == 2 :
		return 1
	return func(n-1) + func(n-2)

n = input()

if n.isdigit():
	n = int(n)
	if 0 <= n <= 20 :
	 print(func(n))
	else :
		quit()

```
추가 체크 사항

1. input 사용
- 파이썬을 코테용으로 공부하니까, 자바랑 달라서 헷갈림
- input()으로 입력을 받을 때 기본은 문자열 형식 => 자료형을 숫자형으로 변환해 주는 코드 작성이 필요함
2. isdigit() 함수
- 해당 문자열이 '숫자'인지 판별
- 숫자인 경우에 문자열을 숫자로 변환하기 위해 사용
3. 재귀함수 설계할 때 케이스를 나누자
- Base Case : 재귀함수 종료하는 부분
- Recursive Case : 자기 자신을 호출하는 부분

다른 사람 풀이

1. 반복문 사용 + 메모이제이션
- 초기값을 설정해 주고
- 식이 제시되었으므로, 초기값을 베이스로 반복문 n번 실행
- 시간복잡도 O(n)
2. 재귀함수 + 메모이제이션
```
def fibo(x):
	global arr

	if arr[x] != -1:
		return arr[x]

	arr[x] = fibo(x - 1) + fibo(x - 2)
	return arr[x]


n = int(input())

arr = [-1] * (n + 2)
arr[0] = 0
arr[1] = 1

print(fibo(n))
```
- [-1]*(n+2) : 파이썬에서 리스트(배열)을 초기화하는 방법
- (n+2) 크기 배열의 요소를 -1로 모든 값을 초기화하겠다는 뜻
- global arr : 함수 밖에 선언된 arr에 접근하기 위해 사용
=> 중복되는 값이 많을 경우 -> 배열에 저장하여 재사용하자 (메모이제이션 기법)
