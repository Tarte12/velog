2.7 요구사항을 잘 이해할 수 있는 문제 영역에 폭포수 모델을 적용할 수 있는 이유를 설명하라
- 폭포수 모델은 '명확히 정의된 요구 사항'과 '변동 가능성이 낮은 문제'에 적합
- 각 단계가 명확하게 구분 + 순차적 진행 -> 잘 정의된 문제에서 효과적

2.8 현대의 개발 프로세스는 근본적으로 반복과 점증의 특징을 갖는 이유를 설명하라

- 빠르게 변화하는 사용자 요구사항에 대응
- 작응 반복 주기로 지속적인 검토와 개선 가능
- 초기 완벽 설계의 어려움을 극복하고 품질 향상

2.9 반복/점증 모델의 반복 과정에서 프로젝트 초기에는 분석 활동에 많은 비용이 소비되지만, 후반부 반복에는 통합 테스트 비용이 급격히 늘어나는 이유를 설명하라

- 초기 반복 : 분석과 설게에 많은 리소스 투자
- 후반 반복 : 기존 모듈 통합과 통합 테스트 비용 증가
-> 반복/점증 모델의 점진적 확장 특성에 기인

2.14 애자일 프로세스는 진화, 가벼운, 자주적 프로세스의 특징을 가짐 -> 각 용어가 의미하는 것을 폭포수 모델과 비교하여 설명하라

- 진화 : 애자일은 반복적인 개선 과정 지원 / 폭포수는 고정된 단계 진행
- 가벼운 : 애자일은 문서 최소화 / 폭포수는 무겁고 명세 중심
- 자주적 : 애자일은 팀이 자율적으로 목표 설정 / 폭포수는 관리자가 주도

2.15 단순 설계와 사용자 상호작용을 중시하는 XP 프로세스가 구현에서 리팩토링과 테스트에서 희귀 테스르르 강조하는 이유를 설명하라

- 리팩토링 : 단순 설계로 인해 발생할 수 있는 코드 복잡도 최소화
- 테스트 : 지속적 사용자 피드백 반영 및 품질 보장

2.17 다음은 UP 프로세스에서 언급하는 단계와 작업흐름과 관련된 용어를 보임 -> 각 문제가 설명하는 용어를 보기에서 선택하라
보기
1) 행상/변경 관리
2) 시작
3) 테스트
4) 요구
5) 프로젝트 관리
6) 비즈니스 모델링
7) 구현
8) 설계
9) 전이 
10) 구축
11) 환경
12) 배치
13) 분석
14) 정제
문제
1) 분석/설계 모델링 작업을 주로 수행하는 단계 -> 설계
2) 시스템의 기본적 요구와 제한조건을 상위 수준에서 정의하는 단계 -> 시작
3) 테스트와 배치 작업을 주로 수행하는 단계 -> 전이
4) 대부분의 요구를 파악하고 안정시키는 단계 -> 정제
5) 구현 작업을 주로 수행하는 단계 -> 구축
6) 개발 방법과 무관하게 수행할 수 있는 단계 -> 환경
7) 시작 단계에서 주로 수행하는 공학 작업 흐름(2개 선택) -> 비즈니스 모델링, 요구
8) 정제 단계에서 주로 수행하는 공학 작업 흐름(2개 선택) -> 분석, 설계
9) 구축 단계에서 주로 수행하는 공학 작업 흐름 -> 구현
10) 전이 단계에서 주로 수행하는 공학 작업 흐름(2개 선택) -> 테스트, 배치
11) 개발 단계 전반에 걸쳐 꾸준히 수행되는 지원 작업 흐름 -> 형상/변경 관리
12) 구축과 전이 단계에서 주로 수행하는 지원 작업 흐름 -> 형상/변경 관리, 배치
13) 시작 단계에서 주로 수행하는 지원 작업 흐름 -> 비즈니스 모델링

2.20 XP 모델과 Scrum 모델의 공통점과 차이점에 대해 간단히 설명하라

공통점
- 반복적, 점증적 개발
- 고객과의 지속적인 협력
- 소규모 팀 기반

차이점
