## 1. 문제 해석

#### 일단 암호를 찾아야 하는 문제임
#### #암호 조건
- 서로 다른 L개의 알파벳 소문자 (중복 불가)
- 최소 한 개 이상의 모음, 두 개 이상의 자음
- 알파벳은 암호에서 증가하는 순서로 배열
- 암호로 사용했을 법한 문자의 종류는 C가지
- C개의 문자들이 모두 주어졌을 때 암호 구하기
- 증가하는 순서로 배열  
	=> 순서를 이미 정했으므로 뽑으기만 하는 조합을 써도 됨
- C개의 문자 중 L개를 구해서 암호화
- 한 개 이상의 모음, 두 개 이상의 자음
	=> 이 조건을 어떻게 처리해야 하지?
    
#### 예제로 구조 설계
```
예제
4 6
a t c i s w
```
1. L, C를 입력 받아 저장하기
2. C를 모음/자음으로 나누기-> 어떻게 나누지?
3. (모음)C(1), (자음)C(2)를 하면 제약 조건을 만족할 수 있다고 생각했어.
4. 이후에 이미 뽑은 자리를 제외하고 나머지를 구하면 되기 때문에,
(C-3)C(L-3)으로 나머지 암호를 구하기로 했어
5. 그리고 (모음)C(1), (자음)C(2), (C-3)C(L-3)의 원소를 하나로 합쳐서 다시 조합 알고리즘을 계산하면 정답이 나오지 않을까 정리했어.

## 3. 강의 내용
#### 문제 설명
- 조합을 사전순 나열 : 기존 배열을 사전순으로 정렬 -> 조합 알고리즘 사용
ex) arr.sort() -> 정렬하는 함수 sort()
- 모든 조건을 살펴본 후 -> 조건에 해당하는 것만 정답으로
#### 풀이
- 모음, 자음을 판별하는 함수 설정 (제약 조건 설정)
- 조합 알고리즘 전체 돌리는 부분 따로
(유료 강의라서 코드 리뷰는 개인적으로 정리해 놓음)
#### 알아 놓으면 좋은 거
- `arr.sort()`: `arr` 자체를 정렬시키는 코드
- `sorted(arr)`: `arr` 은 변화가 없으며, `arr`을 정렬한 결과를 반환하는 코드
